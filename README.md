# An-Accountancy-Program-Example-as-Windows-Form-App
A Windows desktop application for managing institutional purchases, invoices, and financial records, built with Visual Studio, Microsoft Access, and Excel export functionality.

## Institution Purchase & Expense Management System

A Windows desktop application developed using Visual Studio for an institution's accounting and treasury department. The application helps manage purchases, invoices, and financial records in an organized and efficient way.

### Features
- Purchase and invoice record management
- Financial data storage using Microsoft Access
- Excel export functionality for financial reports and records
- User-friendly interface designed with a UI/UX component library
- Windows desktop application built with Visual Studio

### Technologies Used
- C#
- Visual Studio
- Microsoft Access
- Excel Export
- UI/UX Component Library

Developed as a university project to simplify financial record-keeping and improve the management of institutional purchases and expenses.
